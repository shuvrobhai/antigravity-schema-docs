# Google Antigravity Glossary & Terminology

Alphabetical index of core Antigravity concepts, components, and protocol terms.

- **`AGENTS.md`** — Repository-level agent guidance file declaring essential setup commands, architecture rules, and testing standards. Evaluated during directory walk-up. (Ch 04, Ch 05)
- **Ambient AI** — The paradigm shift from reactive conversational chat to continuous, autonomous background execution alongside the developer. (Ch 02)
- **Artifacts** — Markdown and media files generated by the agent during complex workflows, rendered in the IDE side panel and persisted under `.system_generated/`. (Ch 08, Ch 12)
- **Browser Subagent** — Dedicated autonomous web-agent capability equipped with DOM interaction, visual viewport capture, and session replay recording. (Ch 08, Ch 12)
- **Dynamic Context Engine** — Engine managing token budgets, hierarchical file indexing, knowledge items (KI), and automated conversation transcript compaction. (Ch 07)
- **Evidence Registry** — The grounding catalog indexing empirical verification probes (EV-001..EV-020) and point-in-time source citation archives. (Ch 00, Ch 19)
- **`GEMINI.md`** — Global or workspace-level behavioral instructions, coding constraints, and communication preferences. (Ch 04, Ch 05)
- **Hook Event** — Discrete points in the agent lifecycle (`PreToolUse`, `PostToolUse`, `PreInvocation`, `PostInvocation`, `Stop`) where external scripts intercept execution. (Ch 04, Ch 20)
- **`hooks.json`** — Lifecycle configuration manifest defining hook handlers, matchers, and execution timeouts. (Ch 04, Ch 20)
- **Integrity Gate** — 12-check validation suite verifying structural contiguity, schema parity, evidence grounding, heading hierarchy, and source synchronization. (Ch 00, Ch 18)
- **Knowledge Item (KI)** — Localized, curated repository summaries stored under `<appDataDir>/knowledge/` to prevent redundant research passes. (Ch 07)
- **Manifest Generator** — Pure typed serialization engine for generating valid SKILL, Plugin, MCP, Hook, Agent, and Rule configurations. (Ch 04, Ch 20)
- **`mcp_config.json`** — Model Context Protocol configuration defining local (Stdio) and remote (SSE/HTTP) server connectors. (Ch 04, Ch 08, Ch 20)
- **Model Routing** — Dynamic allocation of complex reasoning to Gemini Pro tiers and rapid execution/linting to Gemini Flash tiers. (Ch 10)
- **`plugin.json`** — Package manifest grouping skills, rules, MCP connectors, and subagents under a unified namespace. (Ch 04, Ch 20)
- **Progressive Disclosure** — 3-phase loading mechanism (Metadata → Instructions → Resources) preventing context window exhaustion in agent skills. (Ch 04)
- **Reactive Wakeup** — System notification mechanism waking the agent when background asynchronous processes or tasks finish, eliminating polling. (Ch 11)
- **Sandbox Architecture** — Containerized execution environment restricting arbitrary terminal commands and network access to declared trusted paths. (Ch 09)
- **Search Index** — In-memory inverted keyword index providing sub-millisecond retrieval across modules, schemas, probes, and citations. (Ch 07, Ch 14)
- **`settings.json`** — Core configuration manifest controlling tool permissions, default approval modes, color schemes, and trusted roots. (Ch 05, Ch 20)
- **Skill (`SKILL.md`)** — Open-standard domain procedure recipe with YAML frontmatter, strict kebab-case naming, and on-demand chapter references. (Ch 04, Ch 20)
- **Statusline** — Terminal footer displaying real-time quota usage, token consumption, active profile, Git branch, and sandbox status. (Ch 05, Ch 14)
- **Subagent** — Scoped, autonomous child agent persona defined in `.agents/agents/<name>.md` with dedicated system prompts and tool access. (Ch 04, Ch 11)
- **Workflow (`.agents/workflows/*.md`)** — Step-by-step procedural automation recipe invoked directly via `/workflow-name` in the chat UI. (Ch 04, Ch 15, Ch 20)
- **Workspace Session Engine** — Headless in-memory workspace session and diff computation engine powering CLI audits and interactive repairs. (Ch 05, Ch 20)
